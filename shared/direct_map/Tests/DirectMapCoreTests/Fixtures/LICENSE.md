This directory contains one fixed public Beijing z15 vector tile and the PMTiles
header from the official Protomaps basemap build dated 2026-10-31. It is a parser
test fixture, never a user position or simulated production navigation.

Source and compressed SHA-256: see source.json.

Map data © OpenStreetMap contributors, available under the Open Database License
(ODbL): https://www.openstreetmap.org/copyright
https://opendatacommons.org/licenses/odbl/1-0/

Protomaps basemap documentation: https://docs.protomaps.com/basemaps/downloads
The header and compressed tile retain their original bytes. No source code from
the reference moto-gps-waveshare project is included.
